phases

Phase 0–1 · Tooling, accounts, machines done jul 13

Pulumi Go programs for Hetzner, then the pivot: no CX23 capacity, so AWS (3× t3a.medium, ~$0.35 per 3-hour lab on credits). The pivot forced the project’s best idea — the provider-agnostic inventory contract.

Phase 2 · kubeadm bootstrap, by hand done jul 14

certs, static pods, etcd, join tokens — cluster up at v1.35.6, deliberately NotReady awaiting a CNI.

Phase 3 · Cilium done jul 14

Cilium 1.19.4 via Helm; nodes Ready, connectivity test 79/80, Hubble running.

Phase 4 · Storage done jul 14

local-path as portable default; EBS CSI opt-in. The IMDS hop-limit-3 bug, debugged with Hubble, was the phase’s best lesson.

Phase 5 · Platform done jul 14

metrics-server, ingress-nginx, cert-manager with DNS-01 on Cloudflare (real certs, closed firewall), hello app, ArgoCD syncing from the private repo.

Phase 6 · Automate & drill done jul 15

  • Drill 1 — teardown → rebuild in ~8 min · caught the SSH-readiness race
  • Drill 2 — rolling upgrade v1.35.6 → v1.36.2, zero downtime
  • Drill 3 — etcd snapshot → destroyed data dir → restore · proven by time-travel markers
  • Drill 4 — unannounced node kill → replacement Ready in ~7 min

Phase 6.5 · Gateway API migration done jul 18

ingress-nginx retired upstream (mar 2026) → Cilium Gateway API (ADR 005): kube-proxy replaced with eBPF, Gateway API v1.4.1, hostNetwork Envoy on the same ports, TLS moved from app manifests to infra. URLs and firewall unchanged through the cutover.

Phase 7 · PostgreSQL in progress jul 18 →

The named end-goal: state you care about, on a cluster you can rebuild.

  • 7.1 ✅ StatefulSet + PVC — identity and data survive pod deletion
  • 7.2 ✅ PgBouncer — pooling, Deployment-vs-StatefulSet, VIP-vs-headless
  • 7.3 — Patroni HA · leader election; DCS choice: ZooKeeper/etcd vs the k8s API
  • 7.4 — Operators · CloudNativePG / Zalando — appreciate what they automate
  • 7.5 — Capstone · Saleor or Supabase end-to-end behind the gateway

Phase 8 · Talos comparison lab planned

Rebuild on Talos Linux and judge it against kubeadm+Ubuntu (ADR 004). Deliberately after Phase 7: the interesting drill is rebuild-with-state, with real Postgres data at stake. Not a provider swap — no SSH means the whole cluster/ layer becomes machine configs + talosctl; infra/ survives unchanged.
